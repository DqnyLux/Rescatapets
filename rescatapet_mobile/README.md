# 📱 RescataPet EC — Aplicación Móvil (Semana 9)

Este subdirectorio contiene el código fuente de la aplicación móvil de **RescataPet EC** desarrollada en **Flutter (Dart)** para el Taller Práctico de la Semana 9.

---

## 🚀 Inicio Rápido

1. **Configurar Variables de Entorno (`.env`):**
   ```env
   # Emulador Android: 10.0.2.2:3000
   # iOS Simulator / Web: localhost:3000
   API_URL=http://10.0.2.2:3000/api
   ```

2. **Instalar dependencias y ejecutar:**
   ```bash
   flutter pub get
   flutter run
   ```

Para una explicación detallada del proyecto, arquitectura, permisos de red y guía completa de evaluación, consulta el [README principal del repositorio](../README.md).
